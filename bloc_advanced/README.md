# Bloc: bigger teams

Bloc the way larger teams set it up: the API client and repository are separate Dart packages, the app is organized by feature, lints are strict, and views are tested with a mock bloc. It shows a list of Rick and Morty characters, cached on the device.

Part of [Flutter Architecture Examples](../README.md).

```bash
flutter pub get
flutter run
```

Run the app tests with `flutter test`, and the package tests with `dart test` in each folder under `packages/`.
